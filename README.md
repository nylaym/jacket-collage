# ジャケットコラージュアプリ 要件定義

## 目的
Spotifyプレイリストのジャケットを並べて1枚の画像にする。SNSでプレイリストを拡散する際の視覚的フックとし、そこから実際に聴いてもらう導線を作る。

## 現状（プロトタイプ済み）
`jacket-collage.html` の単一HTMLファイルとして実装済み。

- Spotify連携：Authorization Code + PKCE方式でログイン（サーバー不要）。スコープは `playlist-read-private playlist-read-collaborative`。
- API制約への対応：2026年2月のAPI変更に対応済み（`/playlists/{id}/items` エンドポイント、`item`フィールド）。他人のプレイリストの曲一覧は取得不可のため、ログインした本人のプレイリストのみを対象とする前提。
- データ取得：`/me/playlists` で一覧→選択→`/playlists/{id}/items`でジャケット取得→アルバム重複除去。
- 描画：Canvas APIで1:1（1080×1080px）に描画。テンプレート3種（フルグリッド／タイトル帯／ポスター）。ジャケットの平均色を抽出してテンプレートの配色に利用。
- 出力：PNGダウンロード、Web Share API対応（モバイル）。
- ログイン不要のデモモード：サンプル画像でテンプレートを試せる。

## 対象範囲（現時点）

- 比率：1:1のみ
- 利用：個人利用のみ（Spotify開発モードの認可ユーザー数に上限があるため、不特定多数への公開は不可）

## 将来的な拡張予定（優先度未確定）

1. 比率の追加：9:16（ストーリーズ）、4:5など。実装上は`RATIOS`定義とテンプレートのレイアウト計算を比率非依存にしてあるので、追加は比較的軽い想定。
2. アートにする画像の選択機能：取得した各ジャケットに表示/非表示のトグルを付ける。データ構造上は各タイルに`selected`フラグを既に用意済みで、UI（サムネイル一覧＋チェック）が未実装。
3. 任意のアートを追加する機能：Spotify取得分以外に、ユーザーが好きな画像をアップロードして並べに混ぜる。タイル構造は`source`（spotify/custom/demo）で区別する設計を先取りしてあるので、ファイル選択UIとローカル画像の取り込み処理を追加する形。
4. テンプレートデザインの拡充：`TEMPLATES`配列に描画関数を追加する形式なので、新規テンプレートはこの形式に沿って増やせる。

## 技術的な注意点・既知の制約

- Spotify Developer Dashboardでアプリ登録が必要（Client ID、Redirect URI設定）。開発モードではDashboardの「User Management」に利用者を個別登録する必要があり、大人数配布は不可。
- ジャケット画像の取得元（Spotify CDN）のCORS挙動により、CanvasからのPNG書き出し（`toBlob`）が失敗する可能性がある。実機確認が必要。
- 認証トークンはlocalStorageに保存（`clientId`, `token`, PKCE `verifier`/`state`）。サーバーは持たない構成。
