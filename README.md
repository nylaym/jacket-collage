# ジャケットコラージュアプリ

## 目的
Spotifyプレイリストのジャケット（またはアーティスト写真）を並べて1枚の画像にする。SNSでプレイリストを拡散する際の視覚的フックとし、そこから実際に聴いてもらう導線を作る。

## 実装状況
`jacket-collage.html` の単一HTMLファイル（サーバー不要）。2画面構成。

### 1. 曲を選ぶ画面
- Spotify連携：Authorization Code + PKCE方式でログイン。スコープは `playlist-read-private playlist-read-collaborative`
- API制約への対応：2026年2月のAPI変更に対応済み（`/playlists/{id}/items` エンドポイント、`item`フィールド、`GET /artists`一括取得の廃止に伴い`GET /artists/{id}`の個別取得へ切替）
- 画像ソース切り替え：ジャケット（アルバム単位で重複除去）／アーティスト写真（アーティスト単位で重複除去、初回切り替え時のみ取得しキャッシュ）
- トラックテーブル：ジャケット・タイトル・アーティスト・アルバム・追加日・リリース日を列表示。列見出しクリックでソート（昇順/降順）
- 絞り込み：アーティスト／アルバム／追加日をポップオーバーでチェックボックス複数選択。絞り込み結果への一括表示/非表示も可能
- ランダム抽出：指定件数（初期値は現在の並べる数にちょうど収まる枚数）をランダムに表示状態にする
- 重複アルバムを非表示：アルバム名が重複するタイルを一括で非表示に
- 表示/非表示はクリックで個別トグル、ドラッグ＆ドロップで並び替え可能
- ログイン不要のデモモード：サンプル画像（ジャケット・アーティスト写真とも）でテンプレートを試せる

### 2. デザイン画面
- 比率：1:1／4:5／9:16／16:9
- 解像度：最高（2倍）／ふつう（基準1080px）／あらい（半分）の3段階、または幅・高さを直接指定するカスタム値（比率固定/非固定を切り替え可能）
- テンプレート3種：フルグリッド／タイトル帯／ポスター。ジャケットの平均色を抽出してテンプレートの配色に利用
- 並べる数：2〜32（最大1024枚）、自動（枚数の平方根から算出）も選択可
- レンガ状敷き詰め：選択枚数ぴったりを過不足なく敷き詰めるjustified rowレイアウト（通常のn×n格子とは別モード）
- 並べ方向：横優先／縦優先
- 出力：PNGダウンロード、Web Share API対応（モバイル）

## 技術的な注意点・既知の制約
- Spotify Developer Dashboardでアプリ登録が必要（Client ID、Redirect URI設定）。開発モードではDashboardの「User Management」に利用者を個別登録する必要があるが、アプリのオーナー自身は登録不要で利用可能
- アーティスト写真の取得（`GET /artists/{id}`）はDevelopment Modeでも動作するが、一括取得（`GET /artists?ids=...`）は2026年2月のAPI変更で廃止され403になるため使用していない
- ジャケット画像の取得元（Spotify CDN）のCORS挙動により、CanvasからのPNG書き出し（`toBlob`）が失敗する可能性がある
- 認証トークンはlocalStorageに保存（`clientId`, `token`, PKCE `verifier`/`state`）。サーバーは持たない構成
- 利用：個人利用のみ（Spotify開発モードの認可ユーザー数に上限があるため、不特定多数への公開は不可）
